What Beacon adds on top of Gemma.

The model is local. The evidence is local. The app controller owns tool access, hidden safety instructions, prompt assembly, and citations.

Run the actual demo.

These are the real local commands used in the project. The comparison script runs base Gemma without tools, then Beacon with offline official evidence.

powershell -ExecutionPolicy Bypass -File scripts\compare_base_vs_beacon.ps1

python scripts\beacon_docs_cli.py list-docs --query "generator carbon monoxide placement" --json

python scripts\beacon_ollama_tool_loop_agent.py --model beacon-gemma4-current-best "Can I run a generator in my garage if the door is open?"
submission framing

Beacon targets Global Resilience and Safety & Trust. It does not claim Ollama is the whole app; Ollama runs the local model while Beacon owns offline official documents and the tool loop.
