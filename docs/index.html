Beacon

A local-first crisis guidance assistant that grounds disaster advice in offline official documents before a local Gemma model answers.

Run the demo Open runbook
user Floodwater touched baby bottle nipples. Can bleach sanitize them?

offline tool cdc_food_after_emergency_chunk_0002
Beacon Throw them out. CDC says sanitizing methods are not effective for removing floodwater contaminants from baby bottle nipples and pacifiers.

citation cdc_food_after_emergency / chunk_0002

Local model, local documents, controlled answers.

Ollama is the model runner. Beacon is the controller that owns the hidden system prompt, offline official-document index, retrieval, tool loop, and citation policy.

Why Beacon beats model memory.

The baseline is plain Gemma 4 E2B with no tools. Beacon uses the same local environment plus an offline official-document controller.

Base Gemma, no tools

Can drift toward generic disinfection advice

For floodwater-contaminated baby feeding items, generic bleach advice is risky because the relevant official rule is a specific exception.

Beacon with offline evidence

Uses the exact CDC exception

Beacon retrieves CDC guidance saying baby bottle nipples and pacifiers touched by floodwater should be thrown out because sanitizing methods are not effective.

Run locally.

These commands run the actual local Beacon path: offline doc tool plus the DPO Gemma model in Ollama.

python scripts\beacon_docs_cli.py list-docs --query "generator carbon monoxide placement" --json

python scripts\beacon_ollama_agent.py --model beacon-gemma4-current-best --force-docs --num-predict 260 --timeout-seconds 360 "Can I run a generator in my garage if the door is open?"
